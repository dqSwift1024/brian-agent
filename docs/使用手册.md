# Brian-Agent 使用手册

本手册说明 Brian-Agent 的启动、关闭与日常管理操作方法。命令行入口为根目录下的 `brian` 脚本，其命令设计参考了 OpenCode 等 Agent 的 CLI 启动/关闭方式（前台 TUI/headless 模式 + 后台守护模式）。

## 1. 环境要求

| 依赖 | 说明 |
|------|------|
| Node.js | 建议 v20+（`dev-server.ts` 经 `tsx` 运行） |
| npm | 随 Node 提供 |
| curl | 用于服务存活探测 |

首次使用前需安装依赖并触发原生二进制拷贝：

```bash
npm install        # 会执行 postinstall 脚本（copy-prebuilt.js）拷贝 prebuilt 二进制
```

可用 `brian doctor` 自检环境与依赖是否就绪。

## 2. 快速开始

```bash
# 环境自检
./brian doctor

# 方式一：后台启动全栈（守护式，适合日常使用 / 部署）
./brian start

# 浏览器打开前端
./brian open

# 查看运行状态
./brian status
```

打开前端后，默认页面为对话页 `/`，后端 API 位于 `http://127.0.0.1:8000`。

## 3. 命令参考

命令格式：`./brian <command> [service]`

### 3.1 全局参数

| 参数 | 说明 |
|------|------|
| `-h` / `--help` | 显示帮助 |
| `-v` / `--version` | 显示版本号 |

### 3.2 后台运行模式（守护式）

| 命令 | 说明 |
|------|------|
| `./brian start` | 后台启动后端 + 前端（默认 `all`） |
| `./brian start backend` | 仅后台启动后端 |
| `./brian start frontend` | 仅后台启动前端 |
| `./brian stop` | 停止后端 + 前端（默认 `all`） |
| `./brian stop backend` | 仅停止后端 |
| `./brian stop frontend` | 仅停止前端 |
| `./brian restart` | 重启后端 + 前端 |
| `./brian restart backend` | 仅重启后端 |
| `./brian restart frontend` | 仅重启前端 |

后台模式将日志写入 `/tmp/brian-backend.log` 与 `/tmp/brian-frontend.log`，进程 PID 记录在 `/tmp/brian-*.pid`。

### 3.3 前台运行模式（对标 OpenCode）

| 命令 | 说明 | 对标 OpenCode |
|------|------|--------------|
| `./brian dev` | 前台启动全栈（后端 + 前端），`Ctrl+C` 一键停止 | `opencode`（TUI 前台模式） |
| `./brian serve` | 前台启动 headless 后端，`Ctrl+C` 停止 | `opencode serve` |

前台模式日志直接输出到当前终端，适合开发调试与容器场景。

### 3.4 其他管理命令

| 命令 | 说明 |
|------|------|
| `./brian status` | 查看后端/前端运行状态与访问地址 |
| `./brian logs [backend\|frontend]` | 实时跟踪日志（默认后端，`Ctrl+C` 退出跟踪） |
| `./brian open` | 在默认浏览器打开前端（前端未运行时自动启动） |
| `./brian doctor` | 环境与依赖自检（基础环境/目录/端口/prebuilt） |
| `./brian clean` | 清理 `/tmp` 下的日志文件与 PID 残留 |

## 4. 端口与配置

| 项目 | 默认值 | 环境变量 |
|------|--------|---------|
| 后端端口 | 8000 | `BRIAN_PORT` |
| 后端绑定地址 | 127.0.0.1 | `BRIAN_HOST` |
| 前端端口 | 5173 | 固定（Vite） |

- 前端经 Vite 代理访问后端：`/api` → `http://localhost:8000`，`/ws` → `ws://localhost:8000`。
- 后端 WebSocket 端点为 `/ws`。

## 5. 常用操作示例

```bash
# 日常使用
./brian start && ./brian open        # 启动并打开前端
./brian status                       # 查看状态
./brian logs frontend                # 看前端日志

# 开发调试
./brian dev                          # 前台全栈，改完代码看日志，Ctrl+C 关闭
./brian serve                        # 只调试后端（headless）

# 维护
./brian restart backend              # 修改后端代码后重启
./brian clean                        # 清理日志残留
./brian doctor                       # 排查环境问题
```

## 6. 关闭方式汇总

| 运行模式 | 关闭方式 |
|---------|---------|
| 前台（`dev` / `serve`） | 终端按 `Ctrl+C`（后端会优雅关闭，含 CDT 停止） |
| 后台（`start`） | `./brian stop`（先 SIGTERM 优雅关闭，超时 SIGKILL 兜底） |
| 单服务 | `./brian stop backend` 或 `./brian stop frontend` |

## 7. 常见问题

| 问题 | 处理 |
|------|------|
| 启动报"后端目录不存在" | 确认在项目根目录执行，或检查 `brian-backend/` 目录存在 |
| 后端启动超时 | 执行 `./brian logs backend` 查看错误日志，通常为依赖或端口占用 |
| 端口被占用 | `./brian status` 确认，或用 `./brian stop` 后重启 |
| 原生依赖报错 | 执行 `npm install` 触发 prebuilt 拷贝，再 `./brian doctor` 确认 |
| 前端无法自动打开 | 手动访问 `http://127.0.0.1:5173` |

> 说明：`npm run dev` 仅执行类型检查 watch（`tsc --watch`）+ 前端 Vite，**不会启动 HTTP 服务**；请使用 `./brian start` 或 `./brian dev` 启动后端。
